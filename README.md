## いちばん簡単な遊び方（ダブルクリック）

- **Windows**: `start-casino.bat` をダブルクリック
- **Mac**: `start-casino.command` をダブルクリック

初回だけ自動でセットアップ（Node.jsが無ければ導入、公開用ツールのダウンロード）をして、
サーバー起動 → 友達用の公開URL作成 → ブラウザで開く、までを自動で行います。
開いたページで「ルームを作る」を押し、表示される招待URLを友達に送るだけです。
ウィンドウを閉じるとゲームが止まります。起動し直すとURLは変わります。

## 手動で起動する場合

    npm install
    npm start          # http://localhost:3000

同じWi-Fi内の友達は `http://<このPCのIP>:3000/?room=ABCD` で入れます。
外のネットの友達とは、下のどちらかで公開してください。

## 友達と遊ぶ（公開方法）

- **Render（無料枠あり）**: このフォルダをGitHubに置き、RenderでNew Web Service → リポジトリ選択
  （`render.yaml`あり、Start Command は `npm start`）。発行されたURLを共有。
  無料枠は放置で休止するため、最初のアクセスに少し時間がかかることがあります。
- **一時的に自分のPCを公開**: `npm start` のまま、別ターミナルで `npx localtunnel --port 3000`
  または `cloudflared tunnel --url http://localhost:3000` を実行し、表示されたURLを共有。

## 構成

- `shared/games/*.js` … 各ゲームのルールエンジン（サーバーとブラウザで共通、通信・画面に依存しない）。大富豪の本体は `shared/rules.js`
- `server/index.js` … Express + Socket.IO。サーバー権威型（手札は本人にだけ送信）
- `public/` … 画面（ビルド不要の素のJS）。ゲームごとの画面は `public/games/`
- `test/` … 大富豪のルール単体テスト、全ゲームのCPU自動対戦（手札の漏えい検査つき）、通信の通しテスト

    npm test

## ゲームを追加するには
`shared/games/` に新しいゲームのファイルを作り、`shared/games/index.js` に1行足します。
ルーム・招待URL・再接続・CPU・タイマーは共通なので、ルール（`create()`が返すエンジン）と
画面（`public/games/<id>.js`）だけ書けば動きます。インターフェースの説明は `shared/games/common.js` の末尾にあります。

## 既知の制限（プロトタイプ）
- カード交換は自動（大貧民は最強カードを渡し、大富豪は最弱カードを返す）
- ルームの状態はサーバーのメモリ上のみ（再起動で消える）
- 切断中の手番は15秒後に自動操作、退室するとCPUが交代
